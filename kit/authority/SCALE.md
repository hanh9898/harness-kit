# Recommended ten-level reference

PSW's Table I (2000, p. 287) describes decision/action selection. Its four-function
model allows differing automation levels; it does not publish a universal numbered
acquisition/analysis ladder. The following compact paraphrase retains the accepted
ten-level reference. A consumer must specify behavior for any function-specific
adaptation rather than imply that the source defines that mapping.

| Level | Decision/action allocation |
| --- | --- |
| 1 | Human decides and acts without computer assistance. |
| 2 | Computer supplies the full alternative set. |
| 3 | Computer reduces the alternatives. |
| 4 | Computer recommends one option. |
| 5 | Computer executes the recommendation after human approval. |
| 6 | Computer executes unless the human vetoes within a limited interval. |
| 7 | Computer executes and necessarily reports afterward. |
| 8 | Computer reports execution when asked. |
| 9 | Computer chooses whether to report execution. |
| 10 | Computer decides and acts while disregarding the human. |

This is a reference scale, not ten permissions or an adoption ladder. Levels 6–10
cannot displace actual review, reporting, logging, grant or stop obligations. A
selected veto mechanism needs a real qualified intervention route; this kit adds
no timer or human-waiting facility. Where a level conflicts with a binding contract,
choose a compatible lower ceiling or an explicit qualified alternative under prior
authority; never relabel the conflict as compliance. In particular, level 10 cannot
justify ignoring a user stop, and levels 8/9 cannot erase selected reporting.

Example (inferred, not a universal default): for a supervised report, authorize
acquisition from an identified public ledger, analysis into attributable summaries,
level-4 release recommendations, and draft-only writes under a separate explicit
grant. State the acquisition/analysis behavior in words; any numbered adaptation
needs its own mapping. Publication stays with its authorized actor. This model
allows useful drafting without conferring release authority or raising task stage.
