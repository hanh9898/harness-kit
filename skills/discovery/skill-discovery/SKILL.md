# Skill discovery

Start with the [proposal entry guard](../../../kit/PROPOSAL-ENTRY.md). A
concrete question goes direct. Follow the [topic route and result contract](../../harness/harness-setup/DISCOVERY.md#topic-route-and-result)
for pass two under `capabilities-discovery`. Return findings and intent inline, without writes.

**Core question:** Which skills should this Harness keep, add or change?

- Compare installed routes, current callers, inputs and outputs against enabled Library candidates and simpler instruction or native-tool options.
- Distinguish default entries, opt-in skills, and exact internal routes. Name the scope, invocation and consumer check for each choice; do not register an override or load a bundle to inspect one skill.
