# Capabilities discovery

Start with the [proposal entry guard](../../../kit/PROPOSAL-ENTRY.md). A
concrete question goes direct. Follow the [topic route and result contract](../../harness/harness-setup/DISCOVERY.md#topic-route-and-result)
for pass one. Return findings and intent inline, without writes.

**Core question:** What capabilities are needed for this work?

- Inventory relevant skills, native tools, CLI, scripts and MCP. Compare supported operations with the requested need, minimal access, credential handling and maintenance.
- Return gaps, viable routes, independent checks and blockers. Record direction for Skills without loading the child topic in pass one; keep CLI, MCP and other tools in this branch.
