# Guidance discovery

Start with the [proposal entry guard](../../../kit/PROPOSAL-ENTRY.md). A
concrete question goes direct. Follow the [topic route and result contract](../../harness/harness-setup/DISCOVERY.md#topic-route-and-result)
for pass one. Return findings and intent inline, without writes.

**Core question:** Which guidance should the agent read first?

- Inspect `AGENTS.md`, host entry points, project standards and the current Glossary/ADR area. Trace precedence and consumers with the repo layout and stack.
- Distinguish instructions from checks that actually enforce policy. Keep useful sources, consolidate duplication only when asked, and report conflicts or missing authority.
- Return the authoritative entry point, its precedence and one consumer check.
