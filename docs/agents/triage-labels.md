# Triage labels

The skills use this mapping for the repo's GitHub Issues:

| Matt triage role | GitHub label | Meaning |
|---|---|---|
| needs-triage | needs-triage | New work whose scope and approach have not been assessed. |
| needs-info | needs-info | Missing specific information or a decision; state exactly what is needed. |
| ready-for-agent | ready-for-agent | Scope, expected outcome, and verification are clear; an agent can start. |
| ready-for-human | ready-for-human | The work is clear but requires direct human implementation. |
| wontfix | wontfix | A decision has been made not to proceed; record the reason before closing. |

Each issue has at most one label from this group. Replace the old label when moving to another state.

Type labels such as `bug`, `enhancement`, and `documentation` are separate and may accompany one triage label. For example: `enhancement` + `needs-triage`, then `enhancement` + `ready-for-agent` once requirements and verification are clear.
