# Set agent authority per task, not by an autonomy switch

A harness records a factory direction for the project and, for each task, a stage and a ceiling on how far the agent may decide within each function type: information acquisition, information analysis, decision selection, and action implementation. This replaces the earlier on/off autonomy switch and the home-made four-axis delegation combination. The basis is Parasuraman, Sheridan and Wickens (2000), with Shavit et al. (2023) for recording and reviewing choices made on a person's behalf and Lee and See (2004) for adjusting levels from observed outcomes. Per-task settings take more setup effort than one switch, but the sources treat authority as a property of each kind of work, and a single switch cannot keep merges and releases under human approval while routine work runs unattended.
