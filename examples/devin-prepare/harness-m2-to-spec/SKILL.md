# Draft the missing spec

Use only via the [opt-in Devin fixture](../../../skills/harness/harness-implement/ROUTES.md#devin-prepare-fixture).
Stop before authoring if the actual project, exact ID, source, revision, caller
or effective invocation policy does not match the verified binding. Reopen the
fixture decision, basis, scope and dependencies. Stop if the handoff and source
disagree or a required reference cannot be opened.

Reuse a current compatible spec if present. Otherwise draft the problem,
chosen behavior, protected scope and publicly observable checks from the
current request and acceptance. Cite the decision revision, basis and
dependencies. Return the spec inline with a ref and revision the caller can
identify in this session; do not treat the ref as durable.

Keep any compatible existing ticket. Return the next step for
[H5 approval](../../../skills/harness/harness-implement/WORK.md#spec-approval-h5);
do not resolve or call the tickets route yourself. Do not load an upstream
original, write files, publish, claim, change Git or add labels.
